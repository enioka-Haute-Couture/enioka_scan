# enioka Scan integration plugin for Cordova and Capacitor

- Simple integration plugin allowing you to launch the provided scan activity and scan service from a Cordova application
- Still requires you to add the enioka Scan dependencies to your Android platform build.gradle
- Requires enioka Scan version >= 3.1.0
- For more information: https://enioka-scan.readthedocs.io/en/latest/enioka-scan-compat-package.html
